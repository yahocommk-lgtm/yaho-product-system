# 야호배대지 상품 자동화 1차 버전

## 실행 방법
1. Python 3.10 이상 설치
2. 터미널에서 이 폴더로 이동
3. `pip install -r requirements.txt`
4. `streamlit run app.py`

브라우저에서 프로그램이 열립니다.

## 현재 기능
- 상품번호 자동 생성
- 중국 상품명/원가/옵션/중량/판매가격 입력
- 상품 사진 업로드
- 상세페이지 초안 생성
- 직원 검수/수정
- 상품 저장 및 목록 관리
- 상세페이지 미리보기
